# PostgreSQL Managed Service - Краткое описание проекта

## Описание для резюме

Разработал полнофункциональный веб-сервис для управления PostgreSQL кластерами с использованием современного стека технологий.

**Технологический стек:**
- Frontend: Next.js 16, React 19, TypeScript
- UI: Tailwind CSS 4, Radix UI, shadcn/ui компоненты
- Аутентификация: NextAuth.js 5 с интеграцией Telegram
- Архитектура: Server Components, Server Actions, API Routes

**Реализованный функционал:**

1. **Система аутентификации**
   - Интеграция Telegram OAuth для авторизации пользователей
   - JWT-токены с автоматическим обновлением (refresh tokens)
   - Защищённые роуты с middleware
   - Управление сессиями (30 дней)

2. **Управление PostgreSQL кластерами**
   - Просмотр списка кластеров с real-time статусами
   - Создание новых кластеров с выбором конфигурации:
     - Версия PostgreSQL (16, 17, 18)
     - CPU (1-8 ядер)
     - RAM (512 МБ - 16 ГБ)
     - Дисковое пространство (10-1000 ГБ)
   - Детальная страница кластера с информацией о подключении
   - Статусы кластеров (running, stopped, creating, deleting, error)

3. **Пользовательский интерфейс**
   - Адаптивный дизайн для desktop и mobile
   - Тёмная/светлая темы
   - Skeleton loaders для улучшения UX
   - Error boundaries и обработка ошибок
   - Empty states для пустых списков

4. **Архитектура**
   - Модульная компонентная структура
   - Server-side rendering для оптимальной производительности
   - API integration с backend сервисом
   - TypeScript для type-safety
   - Оптимизация с кешированием и revalidation

**Объём работы:**
- ~2400 строк кода TypeScript/React
- 70+ файлов (компоненты, страницы, типы, утилиты)
- Полная настройка проекта с нуля

**Ключевые достижения:**
- Создал полноценную систему для управления облачными базами данных
- Реализовал безопасную аутентификацию через Telegram
- Построил масштабируемую архитектуру с использованием best practices Next.js
- Разработал интуитивный UX с современным UI дизайном
